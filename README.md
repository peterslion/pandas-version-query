# pandas-version-query

Counts the records in the [2026 car fuel efficiency](https://raw.githubusercontent.com/DataTalksClub/machine-learning-zoomcamp/main/cohorts/2026/data/car_fuel_efficiency_2026.csv) dataset with pandas.

This environment uses **pandas 3.0.6**. The file has **10,000** data records and 11 columns.

## Run

```bash
python3 -m pip install -r requirements.txt
python3 count_records.py
```
